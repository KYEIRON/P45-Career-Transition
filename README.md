# Project 45 Career Transition OS — V2

This is the responsive HTML dashboard built from the supplied visual reference.

## Files
- index.html — app
- manifest.webmanifest — installable web app metadata
- sw.js — basic offline cache

## Live access
For access from Windows, iPhone, iPad and Android, publish this folder using a static host such as GitHub Pages or Netlify. HTTPS hosting is required for full PWA/service-worker behaviour.

## Notion
The app is intentionally independent of Notion. A later data layer can connect dashboard records to the Project 45 Notion workspace without changing the visual shell.
